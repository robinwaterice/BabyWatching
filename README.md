## 🌟 核心特色 (Core Features)

### 🎮 1. RPG 寶寶演化系統 (RPG Evolution System)
* **陣營傾向值 (`Alignment Score`)**：根據寶寶的日常表現（天使行為加分，惡魔行為減分），陣營傾向值將在 `[-100, 100]` 區間內動態波動。
* **八大演化形態**：隨著等級（XP 經驗值）提升，寶寶會根據陣營傾向量身演化出不同形態：
  * **天使線**：中立寶寶 ➡️ 淘氣小天使 ➡️ 天使 ➡️ **大天使 👼**
  * **惡魔線**：中立寶寶 ➡️ 頑皮小惡魔 ➡️ 惡魔 ➡️ **大惡魔 😈**
  * **中立線**：中立寶寶 ➡️ **混沌混血兒 🌌**
* **動態健康檢測**：一鍵切換寶寶生病狀態，演化角色會立刻切換為「超萌冰敷袋/睏倦」外觀，溫馨提醒勤勞紀錄。

### 📅 2. 智慧年齡分段系統 (Smart Age-Specific Behaviors)
自動依據寶寶生日精準計算月齡，動態切換三大年齡段的專屬天使/惡魔行為清單（徹底告別 1-2 歲出現「完美拍嗝」等不合時宜的選項！）：
* **0-1 歲 (嬰兒期)**：著重於奶量 ml 數、拍嗝、溢奶、炸屎、落地醒等日常生理規律。
* **1-2 歲 (幼兒探索期)**：聚焦於練習湯匙吃飯、用吸管杯自己喝水、換尿布翻滾逃跑（泥鰍寶寶）、Terrible Twos (不要不要期)、揮手拜拜等動作與模仿發展。
* **2-5 歲 (學齡前自理期)**：涵蓋自己吃光飯、嘗試不喜歡的蔬菜、自己穿褲子去馬桶、戒白天尿布、手牽手分享玩具，以及搶玩具、生氣摔東西等社交情緒表達。

### 🛡️ 3. 台灣衛福部常規疫苗排程 (Vaccine Tracker)
* **國家標準同步**：完整收錄 0-5 歲台灣衛生福利部**公費常規疫苗**（必打）與**自費建議疫苗**（選打）時程。
* **智慧提前提醒**：針對即將到來的接種時程，提前 14 天在主頁顯示閃爍提醒氣泡，提示「建議接種」或「可評估」。
* **預約掛號與標記**：直接於 App 內預約接種日期，已完成接種後即可獲得專屬綠色「已完成」徽章！

### 🏆 4. 經典與隱藏彩蛋成就 (Achievements & Easter Eggs)
* **30+ 個經典成長里程碑**：解鎖「翻身大師」、「爬行奇兵」、「牙牙學語」到學齡前的「小小演說家」等成就。
* **隱藏彩蛋解鎖 🎭**：勤勞記錄或觸發特定條件（例如陣營極限、深夜頻繁記錄、醫療護理）時，將無預警解鎖隱藏成就！
* **氣泡點擊智慧定位**：在首頁點擊任何里程碑或隱藏彩蛋氣泡，系統會主動判斷該成就的月齡與類型，**自動切換至正確的年齡分頁與標記**，體驗行雲流水。

### 🎨 5. 極致視覺美學與優質互動 (Premium Design & UX)
* **極光玻璃擬物風 (Glassmorphism)**：馬卡龍配色搭配半透明磨砂質感，高級感滿分。
* **全支援深色模式 (Dark Mode)**：方便爸媽在半夜無光環境下，舒適地記錄寶寶的睡眠與突發狀況，保護雙眼。
* **靈動音效與微交互**：獲得經驗值、寶寶升級、解鎖成就皆配備精心調校的靈動音效，搭配漂浮文字動畫。
* **PWA 手機桌面安裝**：支持 Progressive Web App 標準，可直接安裝至 iPhone/Android 桌面，啟動速度極快。

## 🛠️ 技術棧與架構 (Tech Stack)

* **前端框架**：React 18 & TypeScript (提供最嚴謹的型別安全防護)。
* **樣式系統**：Tailwind CSS (極速打造優雅的 UI 元件)。
* **動畫庫**：Framer Motion (打造滑順如絲的轉場與卡片展開特效)。
* **圖表庫**：Recharts (繪製陣營傾向波折圖，視覺化育兒軌跡)。
* **音效系統**：HTML5 Audio API (高響應低延遲互動反饋)。

## 🚀 快速開始 (Quick Start)

### 1. 安裝與執行
本專案使用 Vite 進行極速建置：

```bash
# 1. 複製專案庫
git clone https://github.com/robinwaterice/BabyWatching.git

# 2. 進入專案目錄
cd BabyWatching

# 3. 安裝依賴套件
npm install

# 4. 啟動本地開發伺服器
npm run dev
```
啟動後在瀏覽器打開 [http://localhost:5173/](http://localhost:5173/) 即可開始遊玩！

### 2. PWA 安裝至手機
當您在手機瀏覽器打開部署好的網站時，點擊導覽列或設定頁面中的 **「📲 安裝至手機桌面」** 按鈕，即可像一般 App 一樣離線快速啟動！

## 💡 為什麼我們推薦 BabyWatching？

1. **化焦慮為樂趣**：傳統的育兒 App 總是充滿了冷冰冰的數字與醫療圖表。BabyWatching 透過 RPG 機制，將「寶寶哭鬧」幽默地包裝為「惡魔屬性爆發」，大幅緩解了新手父母的產後焦慮與緊繃情緒。
2. **極致的互動細節**：不論是飄落的 XP 經驗值微粒、深夜點擊自動適配的暗色面板，還是解鎖彩蛋時傳來的悅耳音效，都讓「記錄」這件事變得極具儀式感與滿足感。
3. **完全在地化的疫苗時程**：內建衛福部最完整、最即時的幼兒接種指引，是父母口袋裡最可靠的健康護理顧問。
